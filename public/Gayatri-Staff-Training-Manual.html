1. How to open staff software

  1. Open the Gayatri website in Chrome or Edge (recommended).
  2. Click Staff in the top menu (or scroll to the Staff section on the home page).
  3. You enter the staff panel — left menu shows Dashboard, Calendar, Reservations, etc.
  4. Use the same computer every day if possible — bookings are stored in this browser (not in the cloud yet).
Important: If you open the software on a different PC, you will not see yesterday’s bookings unless data was backed up. Always use the main front-desk computer for live work.

Refresh if something looks wrong

Press Ctrl + Shift + R (hard refresh) after updates. Do not use browser “Clear all data” — that removes all bookings.

3. The 4-step booking process

Every hall or room booking follows this order. The grey bar on the Reservations page is a guide, not a live booking.

1 Reservations → 2 Payment & Invoice → 3 Guests / CRM → 4 Documents
StepActionResult
1 Enter guest details, pick hall/room, agree terms, click Confirm reservation Booking created · calendar blocked · bill opened
2 Record advance or full payment · print bill / receipt Payment history · AR/RC/TX documents
3 Verify guest in CRM · add notes · WhatsApp / call Guest record for repeat bookings
4 Upload ID, contract, advance proof Complete KYC file for the booking
Rule: Never skip Step 1. Do not take payment in a notebook only — always create the reservation in the software first so the calendar stays correct.

4. Step 1 — New reservation (detailed)

1 Go to Reservations → click + New reservation

2 Fill Guest section:

  • Name and Phone — mandatory (10–15 digits)
  • Customer GST — only if billing to a company
  • Event type — Marriages, Conference, Seminar, etc.
  • Source — Direct, Walk-in, Website, Corporate, etc.
  • Event date — must be today or future
  • ID type & number — for records
  • Expected guests — delegate / pax count

3 Select Hall (convention booking):

  • Click the hall card (Imperial Ballroom, Garden Pavilion, or Heritage Courtyard)
  • Choose Half day or Full day (24h) only
  • If hall shows as booked, pick another date or hall — do not force through
  • Tick Convention Terms & Conditions checkbox

4 Select Room (optional — if guest also stays):

  • Click an Available room on the floor plan
  • Set check-in / check-out dates
  • Tick Room Booking Terms & Conditions

5 Review the Estimate panel (subtotal, GST, total, balance)

6 Optionally attach documents at booking time (or upload later in Step 4)

7 Click Confirm reservation

Errors that block confirm: Missing name/phone · No hall or room selected · Hall already booked · Terms not ticked · Invalid phone format

5. Step 2 — Payment & Invoice

After confirm, you are taken to the bill automatically. You can also open from Reservations → Payment button.

Collect payment

  1. Open the booking bill (Payment & Invoice)
  2. Scroll to Collect remaining form
  3. Enter Amount, Payment date, Mode (Cash / UPI / Card / Net banking / Bank transfer)
  4. Choose Kind: Advance (first payment) or Payment (settlement)
  5. Submit — balance updates automatically

Print bill / PDF

Click Print / PDF (top right) → choose “Save as PDF” or print on A4.

Issue documents

At the bottom, click chips to issue: Quotation, Proforma invoice, Tax invoice, Advance receipt, Payment receipt, Final invoice, etc. Each gets a unique number (AR, RC, TX…).

GST: Bill shows Gayatri GST and customer GST (if entered). Hall hire + 18% GST is calculated on the estimate panel during reservation.

6. Step 3 — Guests / CRM

  1. From Reservations, click CRM on a booking row
  2. View guest name, phone, address, GSTIN, ID proof
  3. See all live bookings for this guest
  4. Use WhatsApp or Call buttons to contact guest
  5. Edit guest details if guest provides corrections

Guests appear automatically after Step 1 confirm. One guest can have multiple bookings over time.

7. Step 4 — Documents (KYC & proofs)

From Reservations → Documents, or Payment page → KYC documents.

Hall booking — required documents

  • Booking party photo ID (Aadhaar / PAN / Passport)
  • Address proof
  • Signed hall contract
  • Advance payment proof (UPI screenshot / bank slip)

Room stay — required documents

  • Guest photo ID
  • Guest photograph

How to upload

  1. Click document type chip at bottom (e.g. “Guest photo ID”)
  2. Choose PDF or image (JPG, PNG) — max 8 MB per file
  3. File is saved on this computer (browser storage)
  4. Green tick = uploaded · Red = still required
Do not rely only on paper files — upload in software so any staff member can see proofs before the event date.

8. Calendar — check availability

  1. Open Calendar from the left menu
  2. Navigate month using arrows
  3. Each day shows hall bookings — colour blocks per hall
  4. Click a booking to open Payment & Invoice
  5. Before confirming a new reservation, always cross-check the event date here

Cancelled bookings do not block the calendar. Active and confirmed bookings do.

10. Event projects (run-sheet)

When a hall booking is confirmed, an event project is created automatically under Events.

  • Tasks: Hall, Rooms, Catering, Decoration, Photography, DJ, Parking, Security, Stage
  • Assign vendor names and move status: Pending → In progress → Done
  • If booking is cancelled, event disappears from this list

Catering, decoration, DJ are organised by the guest — Gayatri provides venue only. Tasks help your team track coordination.

11. Reports — collections & cancellations

Collections tab

  1. Reports → Collections
  2. Set From / To dates (Today · This month · All dates)
  3. Filter: All · Hall · Room stay
  4. View Cash, UPI, Advance, Balance totals
  5. Download Excel or Print / PDF for accounts

Cancellations tab

  1. Reports → Cancellations
  2. See all cancelled bookings with date, billed amount, refund
  3. Click View bill to see historical bill (read-only)

12. Cancel a booking (do not delete)

On Reservations → Active list → click Cancel (red button).

  • Booking stays on record under Cancelled tab and Reports → Cancellations
  • Calendar and hall hold are released immediately
  • Software asks if you want to record a refund if payment was collected
  • Event run-sheet is removed from Events page
Do not use “Reload demo property data” in Settings — that resets all master data.
Clean start (Dashboard or Settings) clears ALL bookings — use only when starting fresh, not for single cancellations.

14. Common mistakes to avoid

Taking payment without creating reservationAlways Step 1 first, then payment
Forgetting to tick Terms checkboxesHall terms for hall · Room terms for rooms
Wrong slot typeOnly Half day or Full day (24h) — no hourly

15. Daily checklist for front desk

  • Open staff software on the main desk computer
  • Check Dashboard — today’s bookings and hall status
  • Check Calendar for the next 7 days
  • Follow up balance due from Payment & Invoice list
  • Upload missing documents for upcoming events
  • Update room housekeeping status after check-outs
  • Record all cash/UPI in software the same day
  • Use Cancel (not delete) if guest cancels — record refund if applicable
  • End of week: Reports → Collections → Download Excel for accounts
